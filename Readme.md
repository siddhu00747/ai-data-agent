# AI Data Agent — Starter

## What this is
Full-stack starter for the assignment: upload any Excel, ask natural-language questions, get SQL-generated answers + charts.

Stack: React (Vite) frontend + FastAPI backend + DuckDB for analytics. LLM integration is optional (OpenAI stub available).
